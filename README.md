Это отдельный репозиторий для скачивания тестовой сборки. Аккаунт GitHub и приглашение в команду для скачивания не нужны. Исходный проект здесь не публикуется; ZIP содержит готовые минифицированные файлы плагина.

## Что умеет

- Семь настроек искажения: наклон, дуга и перспектива по горизонтали и вертикали, плюс глубина.
- Ручной Warp за четыре или восемь точек прямо на холсте Figma.
- Работа с текстом, фигурами, группами, фреймами, Auto Layout и компонентами. Поддерживаемые эффекты остаются живыми; сложные случаи используют растр.
- Редактирование до четырёх строк текста с одним стилем, пресеты, копирование настроек, черновики и отмена действий.
- Компактный режим с котёнком, который приостанавливает искажение.

## Установка

1. Скачайте **бета-архив по ссылке выше**. Кнопка GitHub «Code → Download ZIP» скачивает только документы репозитория.
2. Полностью распакуйте архив в постоянную папку на компьютере.
3. Откройте настольное приложение Figma.
4. Импортируйте `DEFFO-FX-BETA/manifest.json` как плагин разработки: **Plugins → Development → Import plugin from manifest**.
5. Запустите **DEFFO FX** из списка плагинов разработки.

Если уже установлена локальная RC16, закройте плагин, замените `plugin.js` и `ui.html` файлами из архива и запустите снова. Зарегистрированный ID не менялся.

## Тестирование

Проверяйте на копиях макетов. Если нашли ошибку, сохраните шаги воспроизведения, тип объекта, значения настроек и короткую запись экрана. Можно сообщить об ошибке через [Issues](https://github.com/dimaonsa/DEFFO-FX-Beta/issues).

В сборке есть английская справка Info и русская инструкция `START-HERE-RU.txt`. Сборка работает локально, без активации и срока отключения.
